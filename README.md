# LIVE STUDIO website

Lightweight bilingual static website prepared for GitHub Pages.

## Publish on GitHub Pages

1. Push this folder to a GitHub repository.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

The site uses relative asset paths, so it works on both a custom domain and a project Pages URL.

## Before launch

- Replace or add portfolio media in `assets/media` as new work becomes available.
- In `index.html`, replace `REPLACE_VIDEO_ID_1` through `REPLACE_VIDEO_ID_4` with the corresponding YouTube video IDs.
- Add a business email or messenger link when ready; current calls to action open `@tivat.studio` on Instagram.
- Update the Open Graph image if you add a dedicated 1200 × 630 social preview.
